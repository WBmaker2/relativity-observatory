## 2026-09-23

- 상대성 관측소 P0 첫 화면을 만들었다. 사건 설정, 장면, 좌표 표, 시공간 도표, 기록 흐름이 한 페이지에서 이어진다.
- β=0.6 예제(A·B 동시가 S′에서 1.5초 차이로 벌어짐), 빛 도착 시간과 사건 시간 분리, 간격 분류를 수치와 도표로 함께 보여준다.
- 입력 범위를 벗어나면 이전 값을 유지하고 이유를 알려준다. 키보드와 320px 작은 화면, 움직임 줄이기 설정을 함께 고려했다.
- 배포 준비를 시작했다. 사용 설명서와 검증 기록, 배포 점검표를 만들었다. 아직 배포하지 않았다.
- 빈칸 입력과 깨진 저장 기록에도 화면이 깨지지 않게 다듬었다. 작은 화면 320·360·768·1280px과 하위 경로에서도 동작을 확인했다. 입력 반응은 100ms 안이다.
- 교과 검토를 마쳤다. 수치를 직접 다시 계산해 화면과 일치함을 확인했고, 시간 지연 공식 남용 금지 한 줄을 화면에 덧붙였다. 배포를 막을 문제는 없었다.
- 깃허브에 공개하고 페이지스 배포를 마쳤다. 공개 주소에서 수치·화면·업데이트 내역이 정상 동작함을 직접 확인했다.
- 움직임 줄이기·고대비·접근성 트리를 실측했다. 펄스 대체·시스템 색상 전환·대비율 AA·컨트롤 이름 23개 전부를 확인했고, 실제 스크린리더 낭독은 사람 확인으로 남겼다.
- 교과 권고에 따라 고유시간 예시(β=0.6에서 이동 시계 1초는 S에서 1.25초)를 화면 안내에 한 줄 덧붙였다.
