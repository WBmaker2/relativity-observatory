# 이미지 자산 명세 (P0 도입 3장)

- 상태: 제작 전. 생성 이미지에 수치·정답을 맡기지 않는다(시계·사건·빛·좌표는 엔진이 그림).
- 모델: image 2.5 가용 미확인. 이 환경에는 이미지 생성 도구가 없고, ego-browser CLI는 있으나 Google Flow 로그인은 사용자 본인 계정으로 직접 해야 한다. 다른 모델로 조용히 대체하지 않고 사용자와 협의 후 제작한다.

## 공통 제약 (3장 모두)

- 시계 숫자·빛 화살표·물리 수식·측정 눈금 없음 (별도 레이어 합성용).
- 중앙은 넓게 비운 구도 (제목·시작 버튼 자리).
- 원근 왜곡이 길이 수축으로 오인되지 않게 도입 삽화임을 표시하고 계산 화면과 구분한다.
- 가상 자료 표시: '교육용 가상 삽화' 문구와 함께 사용. 실제 관측 사진처럼 쓰지 않는다.
- 목표: 카드당 150KB 이하 WebP, 주요 장면 500KB 이하. 문자 합성 전 압축.

## 자산 목록

### intro-train (도입 1: 열차)
- 목적: 첫 화면 질문 옆 도입 삽화. 움직이는 열차의 도식적 인상만 전달.
- 프롬프트 초안: '가상의 미래 열차 교육용 도입 삽화, 옆면 도식, 중앙은 넓게 비운 구도, 시계 숫자·빛 화살표·물리 수식 없음, 밝은 배경'
- alt 초안: '교육용 가상 열차 도입 삽화 (수치 없음)'
- 검수: 열차 길이가 특정 값으로 읽히지 않는지, 화살표·숫자가 없는지.

### intro-platform (도입 2: 플랫폼)
- 목적: 플랫폼 양끝 섬광 설정의 맥락 삽화.
- 프롬프트 초안: '가상의 미래 기차 플랫폼 교육용 도입 삽화, 양끝 구조물 대칭 배치, 중앙은 넓게 비운 구도, 시계 숫자·빛 화살표·물리 수식 없음, 밝은 배경'
- alt 초안: '교육용 가상 플랫폼 도입 삽화 (수치 없음)'
- 검수: 양끝 대칭이 '동시' 단서로 읽히지 않는지 (빛 도달 순서는 엔진 표로만 판단).

### intro-observatory (도입 3: 관측소)
- 목적: 관측·기록 흐름의 맥락 삽화.
- 프롬프트 초안: '가상의 관측소 교육용 도입 삽화, 망원경 대신 탁자 위 도표와 연필, 중앙은 넓게 비운 구도, 시계 숫자·빛 화살표·물리 수식 없음, 밝은 배경'
- alt 초안: '교육용 가상 관측소 도입 삽화 (수치 없음)'
- 검수: 실제 관측 장비·기록처럼 보이지 않는지.

## 제작 흐름 (공통 원칙 §5)

1. 이 명세 확정 → 2. 스타일 기준 1장 시험 → 3. 일관성 검수 → 4. 3장 제작 → 5. 압축 → 6. 앱 삽입 → 7. 실제 화면 검수.
- 자산 레코드(id·purpose·promptVersion·modelUsed·alt·dimensions·licenseNote·reviewStatus)는 제작 시 기록한다.
- 유사 시도 3회 실패 시 중단하고 대안(도식 SVG 유지)을 사용자와 협의한다.
