# 검증 기록 (P0, 배포 직전)

작성일: 2026-09-23. 대상: 배포 직전 상태. 측정값은 기록일 뿐 교육 효과 검증을 뜻하지 않는다.

## 1. 모델 검증

- β=0 항등 변환, β→-β 왕복 1e-10 이내 복귀: `tests/engine.test.js` 통과.
- 설계서 예제 β=0.6 네 수치 고정 테스트: A′(0.75,-1.25), B′(-0.75,1.25) 통과.
- Δs² 변환 전후 보존, 빛 기울기 ±1 보존: 통과.
- 같은 시계 고유시간 1초 → S에서 1.25초 (β=0.6): 통과.
- 미래 시간꼴/빛꼴 순서가 β∈[-0.9,0.9]에서 역전되지 않음: 통과.
- 수신 교점은 방출보다 미래이며, S 수신을 S′로 변환한 값과 S′에서 직접 푼 값이 일치: 통과 (B 0.625초, A 2.5초).

## 2. 데이터 검증

- 기록 스키마: schemaVersion, appId, createdAt, scenarioId, parameters, seed, observations, prediction, explanation, engineVersion.
- 손상된 localStorage(JSON 파싱 실패·형태 불일치)는 빈 목록으로 복구하고 화면을 깨지 않는다. (경화 완료: 기록 항목별 형태 검사 + HTML 이스케이프)
- 탭을 숨기면 재생이 멈추고, 돌아오면 멈춘 자리에서 직접 다시 시작한다. 수치 상태는 그대로 둔다.
- seed: P0은 결정적 계산이라 null 저장. 난수 없음.

## 3. UI 검증

- 한 학습 흐름(예측→관찰→비교→기록 저장)을 실제 브라우저에서 수행: 통과 (1280px, B-first 예측 저장 확인).
- 키보드: 시간 커서 ←/→ 0.05 이동, 탭 순서, 대화상자 Esc 닫기/포커스 복귀: 통과.
- 가로 넘침: 320·360·768·1280px에서 페이지 넘침 없음. 최종 QA 4개 폭 전부 scrollW==viewport로 통과.
- 움직임 줄이기: gi-pulse 정적 테두리 대체 CSS 확인 (`prefers-reduced-motion` + `pulse-aura` 존재). 실제 OS 설정 에뮬레이션은 MCP 미지원이라 사람 확인 필요.
- 오류 복구: 범위 밖 β·사건 입력 + 빈칸 입력 시 이전값 유지 + 이유 표시 통과 (빈칸: ‘숫자를 입력하세요. 이전 유효값 0.6 유지.’).
- 손상 기록 복구: localStorage에 깨진 문자열 저장 후 새로고침해도 ‘저장된 기록 없음’으로 정상 표시 통과.
- 하위 경로(`/relativity-observatory/`)에서 비교 수치·대화상자·UPDATELOG 로드까지 동작 확인.
- 2D 대체: WebGL 없이 SVG+표로 전 과제 수행 가능. Three.js 미사용이므로 대체 화면이 기본 화면이다.

## 5. 교과 검토

- 상태: 미완. 테스트 통과와 수업 효과는 별개로 본다.
- 확인할 점: ‘멀리서 늦게 보임 = 시간 지연’ 오개념 방지 문구, 공간꼴 순서 변화를 오류처럼 표시하지 않음, 음의 t′ 설명, 시간 지연 Δt=γΔτ 남용 금지 문구가 화면에 그대로 있는지.
- 공식 성취기준 매핑은 별도 검토가 필요하다.
