## 1. 수치 직접 검증 (전부 손으로 재계산)

- γ(0.6) = 1/√(1-0.36) = 1/0.8 = 1.25. 화면 표기(γ=1.25) 일치.
- A(0,-1) → t′=1.25×(0-0.6×(-1))=0.75, x′=1.25×(-1-0)=-1.25. 화면·테스트 일치.
- B(0,1) → t′=1.25×(0-0.6×1)=-0.75, x′=1.25. 화면·테스트 일치.
- Δs² = 0²-2² = -4 (공간꼴). ‘인과 역전이 아님’ 판정과 일치.
- 플랫폼 중앙 수신: 거리 1광초 → t=1 동시. 일치.
- 이동 관찰자(v=0.6) 수신: B는 (0-1)/(-1.6)=0.625초, A는 (0+1)/0.4=2.5초. 화면(0.63·2.50) 일치.
- 고유시간: S′ 원점 시계의 1초는 S에서 1.25초. 엔진 테스트로만 검증되고 화면에는 없음(§4 권고).

## 4. 권고 (배포 차단 아님)

1. 비교 카드나 좌표 카드에 한 줄 추가 권장: ‘시간 지연 Δt=γΔτ는 같은 시계의 두 사건에만 쓴다. 서로 다른 장소의 임의 사건에 바로 적용하지 않는다.’ 설계서 §5 문장을 쉬운 말로 옮기면 된다.
2. 고유시간 1초→1.25초 예시는 테스트에만 있고 화면에 없다. P0 범위 안에서는 전이 과제 문장으로 충분하지만, 교사가 수업에서 물을 수 있으니 설명 예시로 한 줄 있으면 좋다.
→ 반영 완료 (2026-09-23): 좌표 카드 안내 문구에 ‘(예: β=0.6에서 이동 시계 1초는 S에서 1.25초로 잰다.)’ 추가.
3. 공식 성취기준(학3382-...) 매핑은 하지 않았다. 학교급 공식 문서와 별도 대조가 필요하다.
4. 이미지 자산(P0 도입 3장)은 미포함. 현재 SVG 도식으로 전 과제 수행이 가능하므로 배포 차단은 아니며, 도입 삽화를 넣을 때는 수치·수식을 이미지에 넣지 말고 계산 화면과 구분한다는 검수 조건을 그대로 적용해야 한다.
